# Backbeat Studio Website

Website company profile statis untuk GitHub Pages.

## File
- `index.html` — struktur dan konten website
- `assets/style.css` — tampilan dan responsive layout
- `assets/script.js` — menu mobile dan tahun otomatis

## Upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `backbeat-studio`.
2. Pilih **Public**.
3. Upload `index.html`, folder `assets`, dan `README.md` ke root repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
7. Tunggu proses deployment selesai. URL biasanya `https://USERNAME.github.io/backbeat-studio/`.

Jika nama repository adalah `USERNAME.github.io`, URL website menjadi `https://USERNAME.github.io/`.
